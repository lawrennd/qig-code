# CIP-0007: Analytic Forms for S and A via Lie Algebra Structure

## Closure Note (2026-06-13)

This CIP is closed as superseded. The su(9) symbolic programme it proposed is not
required by either the origin paper or the Hamiltonian-emergence paper. The two
deliverables worth preserving are:

- **`qig/symbolic/lme_exact.py`** — exact ρ, ρ₁, ρ₂, marginal entropies, constraint
  gradient, and Fisher information at LME states via the 9×9 → 3×3+2×2+1×1×4 block
  decomposition. Machine-precision results (~10⁻¹⁵). This is used as a validation
  tool in CIP-000C tests.
- **`qig/symbolic/exact_exp_k.py`** — separable-case exact exponentiation
  exp(A⊗I + I⊗B) = exp(A)⊗exp(B).

Superseded by **CIP-000C** (Gibbs-Lock API and μ₀ Inference), which provides the
Gibbs-locked-frame API that both papers require, using the above symbolic machinery
for validation rather than as a production path.

## Summary

Develop symbolic/analytic expressions for the symmetric (S) and antisymmetric (A) 
parts of the GENERIC decomposition Jacobian for quantum systems using Lie-algebraic 
operator bases. Similar to the harmonic oscillator implementation which has 
`antisymmetric_part_analytical(theta)`, create analytic forms for the quantum 
qutrit case that exploit structure constants and block structure to achieve 
significant simplifications.

## Motivation

**Current state**: The quantum implementation computes S and A purely numerically 
by decomposing the full Jacobian M computed via automatic differentiation:
```python
M = self.jacobian(theta, method='duhamel')  # Numerical
S = 0.5 * (M + M.T)
A = 0.5 * (M - M.T)
```

**Problems**:
1. Numerical computation obscures geometric structure
2. Third derivatives of ψ are expensive to compute numerically
3. Cannot directly see how Lie algebra structure creates simplifications
4. Difficult to verify theoretical properties analytically

**Opportunity**: The Lie-algebraic structure provides multiple sources of 
simplification that aren't exploited:

1. **Structure constants**: Commutation relations [F_a, F_b] = 2i Σ_c f_abc F_c 
   create systematic zeros when operators act on different sites

2. **Block structure**: For independent pairs at LME origin, all geometric objects 
   (G, a, M, S, A) decompose into independent blocks

3. **Analytic formula for A**: From equation (283) in quantum-generic-decomposition.tex:
   ```
   A = (1/2)[a⊗(∇ν)ᵀ - (∇ν)⊗aᵀ]
   ```
   This is *simpler* than the full Jacobian—it only depends on constraint geometry

4. **Tensor contractions with structure constants**: Third derivatives of ψ interact 
   with f_abc in ways that should produce cancellations

**Evidence from classical case**: The harmonic oscillator (3 parameters) has 
analytic forms computed via SymPy that reveal the geometric structure as 
polynomial ratios. Despite complexity (degree-7 denominators), these expressions:
- Validate numerical implementations to machine precision
- Reveal factored structures (e.g., A_12 = -4θ_pp θ_xp² θ_xx (θ_pp² - θ_xx²)(...) / D²)
- Enable symbolic verification of properties (Jacobi identity, etc.)

**Goal**: Achieve the same for quantum systems, focusing on:
- Single qutrit pair (2 qutrits, 16 parameters)
- Exploiting Lie structure for simplifications beyond what classical case has
- Creating reusable symbolic computation infrastructure

## Detailed Description

### Mathematical Foundation

The antisymmetric part has an explicit geometric form:
```
A = (1/2)[a(∇ν)ᵀ - (∇ν)aᵀ]
```

where:
- `a = ∇(Σ_i h_i)` is the constraint gradient (marginal entropies)
- `ν = (aᵀGθ)/(aᵀa)` is the Lagrange multiplier
- `∇ν` involves third derivatives of ψ, constraint Hessian, and metric contractions

**Key insight**: This formula is *independent of most of the Jacobian complexity*. 
We don't need to compute the full M symbolically—only the constraint geometry 
(a, ν, ∇ν).

### Natural Parameter Interpretation

**Important clarification on parameter values:**

- **θ = 0**: Maximally mixed state (ρ = I/D)
- **θ → -∞** (large negative): Locally maximally entangled (LME/Bell) states

For regularized LME states (ε ~ 10⁻³), parameters are finite but large:
||θ|| ~ 3 with some components around -3.

This means:
- "Near maximally mixed" = small θ values
- "Near LME (Bell state)" = large, negative θ values

### Lie Algebra Simplifications

For Gell-Mann basis {λ_k} on two qutrits:

**Structure constants block pattern**:
```
f_abc = 0  when F_a and F_b act on different sites
```
This means:
- f_abc ≠ 0 only for indices (a,b,c) all ≤ 8 (site 1) or all > 8 (site 2)
- Cross-site terms vanish automatically
- The 16×16×16 structure constant tensor is extremely sparse

**Block structure at LME origin**:
For product state ρ = ρ₁ ⊗ ρ₂:
```
G_total = G₁ ⊕ G₂    (block diagonal)
a_total = a₁ ⊕ a₂    (block separable)
A_total = A₁ ⊕ A₂    (block diagonal)
```

**Implication**: We only need to compute A for a *single* pair (8×8 matrix), 
then assemble via direct sum. Reduces 16×16 problem to 8×8.

## Challenges and Mitigation

### Challenge 1: Symbolic Entropy Computation

**Problem**: von Neumann entropy H = -Tr(ρ log ρ) requires eigendecomposition, 
which is difficult symbolically.

**BREAKTHROUGH: Block Structure of Reduced Density Matrices**

For our qutrit pair system (d=3), the reduced density matrices have special structure:
```
ρ₁ = [[a, b, 0],      (2×2 block + 1×1 block)
      [b, c, 0],
      [0, 0, d]]
```

This means eigenvalues come from **quadratic** (not cubic) formula:
- λ₃ = d (trivial - isolated entry)
- λ₁,₂ = (a+c ± √((a-c)² + 4b²)) / 2

**Result**: 
- Differentiation: 0.08s (was MINUTES with general cubic eigenvalues)
- Accuracy: ratio to numerical ≈ 1.0001 (~0.01% error from ρ Taylor expansion)
- No Taylor approximation needed for accuracy!

**Why this structure exists (SU(3) Lie algebra)**:

The Gell-Mann basis is complete, but SU(3) has a canonical **SU(2)⊕U(1) subgroup**:
- **3 = 2 ⊕ 1** (decomposition of fundamental representation)
- Computational basis: |0⟩,|1⟩ form a 2D subspace, |2⟩ is isolated

The 8 Gell-Mann matrices split accordingly:
| Generators | Matrices | Role |
|------------|----------|------|
| SU(2) | λ₁,λ₂,λ₃ | Mix |0⟩,|1⟩ only |
| U(1) | λ₈ | Diagonal; separates (0,1) from 2 |
| Ladder | λ₄,λ₅,λ₆,λ₇ | Mix |2⟩ with |0⟩,|1⟩ |

**Key insight**: Any state lacking coherences with |2⟩ has **zero coefficients** for 
the ladder operators λ₄,λ₅,λ₆,λ₇, automatically giving 2×2 + 1 block form.

This includes: diagonal states, SU(2)-symmetric states, partial traces of Bell states,
isotropic states, and **most states encountered in practice**.

**References**:
- Byrd & Khaneja, Phys. Rev. A 68 (2003)
- Kimura, Phys. Lett. A 314 (2003)  
- Gamel, Phys. Rev. A 93, 062320 (2016)

1. **Exact with block structure** (`method='exact'`): Fast AND accurate ✓ (DEFAULT)
2. **Taylor approximation** (`method='taylor'`): Fast, ~1% error
3. **General eigenvalues** (without block structure): Slow, avoid

## Breakthrough: LME Block Decomposition (2025-12-02)

**What happened**: During implementation, we discovered that for locally maximally
entangled (LME) states, the 9×9 eigenvalue problem decomposes into much smaller blocks:

```
9×9 → 3×3 + 2×2 + 1×1 + 1×1 + 1×1 + 1×1
```

All eigenvalues are at most **quadratic** - no cubic equations, no Taylor approximation!

### How this differs from the original plan

| Aspect | Original Plan | What Actually Worked |
|--------|---------------|----------------------|
| exp(K) | Taylor expansion (order 2-6) | **EXACT** via eigendecomposition |
| Accuracy | ~1% (order 2) to ~0.0008% (order 6) | **~10⁻¹⁵** (machine precision) |
| Eigenvalues | Avoided (too complex) | Computed exactly (quadratic formulas) |
| Basis | General su(9) (80 params) | 20 block-preserving generators |
| Scope | All entangled states | LME subspace (sufficient for game) |

### Key Insight: The LME Subspace

LME states like |ψ⟩ = (1/√3)(|00⟩ + |11⟩ + |22⟩) live in a 3D subspace {|00⟩,|11⟩,|22⟩}.

In a permuted basis, K becomes block diagonal. The 20 block-preserving generators:
- **4 local**: λ₃⊗I, I⊗λ₃, λ₈⊗I, I⊗λ₈
- **16 entangling**: λ₁⊗λ₁, λ₁⊗λ₂, λ₂⊗λ₁, λ₂⊗λ₂, λ₃⊗λ₃, λ₃⊗λ₈, etc.

These span the **full** entangled subspace (rank 9), so all maximally entangled
states are accessible while maintaining exact computation.

## Implementation Status

**Note**: Implementation uses su(9) PAIR basis (80 parameters) not local su(3)⊗su(3)

### Qubit/Qudit Generalization

**Current state**: Symbolic code is **qutrit-specific** (d=3, su(9) basis, 80 params)

**Numerical code**: `MatrixExponentialFamily(d=..., n_pairs=...)` handles any d

**Planned next step: Qubits (d=2)**
- su(4) basis for qubit pair: 15 parameters (vs 80 for qutrits)
- Reduced ρ is 2×2 → eigenvalues ALWAYS from quadratic formula
- **No block structure optimization needed** - inherently simple!
- Eigenvalues: λ± = (Tr(ρ) ± √(Tr(ρ)² - 4det(ρ)))/2 = (1 ± √(1-4det))/2
- Create `qig/symbolic/su4_pair.py` following same pattern

**Note on d≥4**: 
- **Exact eigenvalues**: Impractical (need degree-d characteristic polynomial)
- **Taylor approximation**: May be practical—polynomial expressions, no eigenvalues
- **Tradeoff**: Taylor has O(||θ||⁴) error but works for any d
- **Priority**: Focus on d=2,3 first; Taylor-based general d is future option

**Roadmap**:
1. ✅ Qutrits (d=3): Complete with block structure optimization
2. 🔲 Qubits (d=2): Next priority - simpler, good validation
3. ⚠️ General d: Exact eigenvalues impractical, but Taylor expansion may work
   - **Exact eigenvalues**: Block structures are d-specific, formulas don't generalize
   - **Taylor expansion**: H(ρ) ≈ log(d) - (d/2)·Tr[(ρ-I/d)²] is polynomial—no eigenvalues!
   - Cost scales as d⁴-1 parameters, expressions grow but remain differentiable
   - Could implement `symbolic_marginal_entropies_taylor_general(d, theta)` if needed
   - Lower priority: d=2,3 cover most physical systems
